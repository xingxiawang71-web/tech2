项目实践

PPG：三种表示回答不同问题

时域 CNN：学习局部波形与形态。STFT：先构造时频幅度图，各频点沿时间轴标准化，再沿局部时间轴卷积和池化。自相关：对功率谱逆变换得到归一化滞后曲线，编码周期性；它不直接输出 PPI、RMSSD 或临床 HRV 指标。

项目实践

跨模态：位置编码 + 双向注意力

同步后的 epoch 是 token 位置。为 PPG 与 ACC 序列加入正弦位置编码，分别以一条模态作 Q、另一条作 K/V；多头注意力检索另一模态不同 epoch 的信息，残差与 FFN 更新表征，再拼接投影。该实现没有因果掩码。

展开：位置编码、注意力与两种时间尺度

Hₚ = Eₚ(Xₚ) + PE，Hₐ = Eₐ(Xₐ) + PE；两路各自计算 softmax(QKᵀ / √dₖ)V，再经残差更新和拼接投影。

需要区分epoch 内采样时间与epoch 间序列时间：STFT / CNN 先处理一帧信号内的变化，跨模态注意力和后续 TCN / Bi-LSTM 再处理跨帧上下文。双向注意力的权重表示关联，不单独作为生理因果证据。

TCN 使用残差膨胀卷积扩展序列邻域；Bi-LSTM 整合前后文。两者作用不同，是否都有独立增益仍需固定其他条件的消融。

项目实践 · 关键监督设计

Seq2Seq：窗口内每一帧都有监督

模型输出 logits ∈ ℝᴮˣˢˣ⁴，标签为 y ∈ {0,1,2,3}ᴮˣˢ。训练将每个 epoch 的四类 logits 与相应医生标签配对，再计算距离加权损失：L = Σ wₜ ℓ(ŷₜ,yₜ) / Σ wₜ，其中 wₜ = exp(−|t−c|/τ)。中心附近监督权重较高，其他位置也参与训练。

训练：序列各位置参与损失，不只监督中心位置；当前脚本使用带标签平滑的 Focal 损失。
选模与测试：验证集中心帧 Kappa 选模，测试时按对应位置标签计算中心帧结果。
辅助聚合：窗口内不同时间输出的 log 概率平均是另一个规则，不等于同一 epoch 的跨窗口投票，也不与中心帧指标混用。
展开：输入归一化与验证条件

PPG 在每个 epoch 内标准化；ACC 的全局统计由训练集估计并复用于验证 / 测试。信号级预处理带通与 STFT 频率选择分别记录，不能把两者称为同一滤波频段。

以受试者为划分单位，报告分析时间范围、类别映射、标签位置、归一化统计来源与 checkpoint 选择规则。Bi-LSTM、未掩码注意力和对称卷积使用未来上下文，不能由逐帧编码耗时推出即时在线输出。

特征如何进入模型

设计形式希望表达什么实现条件
相对差值xₜ − b当前水平相对个体基线的偏移基线来自低体动候选区间；不称其为金标深睡
相对比值xₜ / (b + ε)相对尺度和幅度变化基线接近零时需保护或改用其他形式
功率对数比值log xₜ − log b功率特征的倍数变化与动态范围只适用于有效正值；下限、裁剪及缺失处理明确记录
一阶差分xₜ − xₜ₋₁邻接epoch之间的变化与已有变化量区分，避免无意义重复差分
项目实践

个体基线：减少绝对尺度的干扰

低体动窗口提供个体基线候选，用稳健统计构造 HR/PPI 和功率特征的相对表示；同时保留基线可用性及信号有效性标记。该设计意图是弱化跨人水平差异，不直接宣称已解决域泛化。

项目实践

CPC：从相关谱提取节律线索

PPI 经清洗、重采样后构造呼吸代理，计算自功率谱、交叉谱和相干性；按实现的相干性加权交叉谱提取频带功率、比值与谱形态。当前两条序列均来自 PPI，呼吸代理并非独立测量。

展开：CPC 相关谱的计算与解释

γ²(f) = |Sₓᵧ(f)|² / [Sₓₓ(f) Sᵧᵧ(f)]；当前实现进一步用 γ²(f) · |Sₓᵧ(f)|² 构造加权谱，再提取频带与谱形态特征。

因此正文采用“CPC 相关谱特征”描述个人实现。同源 PPI 与其滤波代理存在计算依赖；谱关联本身不能证明独立心肺耦合强度，也不直接推出临床睡眠稳定性。与独立呼吸信号对照、代理有效性验证及特征消融是需要单独完成的验证。

展开：训练与实际使用时能获得什么

特征构建不使用医生金标的入睡点或阶段来生成推理输入。低体动候选区间不等于真实深睡；基线选择、缺失值和全夜归一化均需在协议中声明。

当前是离线分析与上下文分类。整夜个体归一化、中心窗口与双向模型含未来信息，若改为在线部署，需要重新设计基线与上下文，并重新训练及评估。

展开：Bad Case 复盘的方法示例

观察到波形振幅与体动异常

  1. 下钻逐受试者结果，并叠加 PPG std、ACC std 与分期。
  2. 检查原始量纲、归一化前后变化及时间同步。
  3. 以受试者级规则标记候选异常，回查准入流程。
  4. 冻结评估集；在训练侧修订准入，再做对照评估。

阶段分布缺类或偏斜

  1. 先检查标签映射、分析窗口和有效时长。
  2. 保留真实病理/人群分布的可能性。
  3. 必要时提出独立医生复核，不假设二标已经完成。
  4. 分别记录标签疑点与模型误判，不合并成确定归因。
